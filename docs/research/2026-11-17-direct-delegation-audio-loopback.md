## File audio and independent output transcription

`scripts/run-asr-coding-probe.ps1 -VoiceLoopback -VoiceScenario capital` runs a temporary local gateway without an agent, synthesizes a fixed French question to a temporary WAV, streams it as microphone input to Vosk, collects the real controller's response and Pocket TTS PCM, then feeds the generated audio to the separately loaded CPU Kyutai STT candidate. The synthetic WAV and candidate's temporary WAV are deleted on normal exit. Audio is not played through a physical speaker. The independent recognizer can make its own mistakes; matching text is not proof of human intelligibility. The wrapper samples whole-system GPU and RAM and can terminate its owned probe on configured thresholds; this is not hard enforcement.

For the capital question, Vosk transcribed `quelle est la capitale de france répond en amont`, the controller answered `La capitale de la France est Paris.`, and Kyutai transcribed the output as `la capitale de la france et paris`. The expected answer appeared in both text and output transcription; normalized WER was 0.143. The automated check matches a whole token and cannot determine whether the answer is negated or semantically correct; the actual text was inspected for this run. Ten samples showed peak dedicated 12,229,447,680 bytes, peak shared 229,752,832 bytes and minimum available RAM 8,548,761,600 bytes. The generated reply was 105,600 bytes at 24 kHz. This is one short synthetic control, not proof of real-room speech or full duplex.

The same process with `-VoiceScenario math` failed its expected-answer check: Vosk transcribed the arithmetic question as `combien font depuis trois répond en amont`, and the controller asked for clarification. Kyutai's transcription broadly matched that clarification (normalized WER 0.158), but neither text nor audio contained the expected answer. Twenty samples recorded peak dedicated 12,219,359,232 bytes, peak shared 227,328,000 bytes and minimum RAM 7,134,023,680 bytes. An earlier run had the same class of Vosk error. This is a real end-to-end failure on synthetic input, not a passing voice conversation. Logs are under `.cache/asr-coding-20261117-192400-118.*` and `-192714-623.*`.

On a later run the capital question again produced `La capitale de la France est Paris.`; the independent Kyutai transcript matched it under the probe's normalization (WER 0.0), with first audio 531 ms after input end. Ten samples showed peak dedicated 12,196,175,872 bytes, shared 241,811,456 and minimum available RAM 11,900,469,248 (`.cache/asr-coding-20261117-234040-803.*`). The repeated arithmetic run transcribed `combien font de plus trois répond en amont`, so the controller asked for clarification. Its long reply included a separate example containing `5`; the old token-presence flag therefore misleadingly reported that the expected answer appeared in text. Independent output transcription did not contain the expected answer, and the overall probe failed (`-234106-404.*`); its 29 samples showed peak dedicated 12,201,287,680, shared 241,811,456 and minimum RAM 11,303,190,528. The independent recognizer also produced many repeated syllables, which could reflect synthesis, recognition or both; no human listening test was performed.

The loopback evaluator now reports input-intent preservation and accepts only a small set of straightforward response forms for these two fixed questions, in addition to retaining the raw token diagnostics. A test rejects an unrelated example containing `5` and a negated Paris answer. This deliberately conservative rule can reject valid paraphrases and is not a general semantic judge. An attempted repeat after this change failed before inference because Pocket TTS was unavailable following a machine restart (`.cache/asr-coding-20261118-190819-138.*`); the later restored services are documented separately. After restoration, another run (`-192220-648.*`) reached the independent ASR step, which returned an empty transcript with exit code zero; the old evaluator failed before retaining other results. It now records empty output as a failed match. A subsequent real-service capital run (`-192251-704.*`) passed the conservative checks: input `quelle est la capitale de la france répond en amont`, text `La capitale de la France est Paris.`, independent Kyutai `la capitale de la france et paris`, normalized WER 0.143, and first audio 406 ms after input end. Ten samples showed peak dedicated 10,927,030,272 bytes, peak shared 75,825,152 and minimum RAM 15,354,781,696. Synthetic input, a token-level checker and sampled resources do not establish physical speech quality or a hard memory limit.

Eighty-one system samples (`.cache/voice-agent-edit-20261122-024601-233.samples.jsonl`) peaked at 11,448,889,344 dedicated and 179,703,808 shared GPU bytes, with minimum available RAM 9,451,364,352; sampling does not rule out transients or spill. A fresh trial workspace `.cache/agent-edit-20261122-0252` was prepared, but two guarded preflights refused the spoken trial before starting services because available RAM was below the 10 GiB requirement (one recorded 9,842,626,560 bytes).
