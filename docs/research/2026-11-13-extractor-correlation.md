# EXP-170: Source correlation for the synthetic extractor test

EXP-169 used French transcription as a weak proxy for separation. We repeated the same mixture and enrollments, comparing each output with each known source using the largest signed normalized cross-correlation within ±200 ms. The mixture correlated 0.9378 with the French source and 0.3931 with the English source. The Hortense-enrolled output correlated 0.9474 with French and 0.2255 with English; the Zira-enrolled output correlated 0.7424 with French and 0.3772 with English. All selected peaks had zero lag in this replay. Extraction took 8.564 and 8.508 seconds respectively for 10.75 seconds of audio, excluding enrollment and ASR.

This suggests attenuation of the competing source with the intended enrollment, but substantial target-source content remained under the competing enrollment. Correlation is sensitive to level, phase and other changes; these are not independent source-level attenuation, intelligibility, identity or real-room quality measurements. There is one synthetic mixture, no physical microphone, no live audio scheduling and no new GPU model. The observed CPU timing cannot guarantee sustained operation alongside concurrent inference. The extractor remains experimental, not a browser feature.

The script now reports both source correlations and retains the source/enrollment hashes. A small synthetic signal test checks correlation alignment and the silent-input case. Reproduce after EXP-169 setup with `.\.venv-voice\Scripts\python.exe scripts/probe-browser-mixture-extraction.py`.
