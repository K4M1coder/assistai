# EXP-167: End-of-speech pause and sentence splitting

The EXP-166 synthetic fixture was generated by Microsoft Hortense from “Bonjour assistant. Peux-tu me raconter une petite anecdote sur la lune ?” Direct Vosk transcription of the complete WAV returned `bonjour assistant peux-tu me raconter une petite anecdote sur la lune`, while the original browser review returned only `bonjour assistant`. At a 2.5% RMS threshold, the fixture contains approximately one second of below-threshold audio between the two phrases. The browser's fixed 700 ms silence timer plausibly split the turn.

The browser now defaults to 1.4 seconds of silence and exposes a 0.6–2.0 second slider. Repeating the same fake-microphone Chrome and real Vosk test produced `bonjour assistant peux-tu me raconter une petite anecdote sur la lune` in a single review, with no user turn submitted. A simulated-frame test verifies that 1.0 seconds of quiet does not end a turn and that 1.4 seconds does. This is one synthetic utterance; it does not establish best latency, recognition in background noise, or a universal pause setting. The longer default adds up to 700 ms relative to the previous timer; push-to-talk ends on release.
