# EXP-198: Current-source cascade demonstration endpoint

The current uncommitted gateway and browser source were started using `scripts/start-windows-demo.ps1 -Port 18096`, with volatile gateway history, the existing loopback Vosk, Pocket TTS, LFM3 Q8 controller, Gemma Q4 agent model and OpenCode services. No model was loaded by this startup. The ownership record is `.cache/assistant/demo-18096-processes.json`; `scripts/stop-windows-demo.ps1 -Port 18096` stops the owned gateway and sampler after checking that record. Other gateway sessions were left intact.

Health reported an experimental gateway with volatile history. Service discovery reported Vosk `vosk-model-small-fr-0.22`, `LFM3-1.7B-Q8_0.gguf` and `gemma-4-12B-it-QAT-Q4_0.gguf` through llama.cpp, Pocket TTS API and OpenCode. This is the cascade, not native speech-to-speech. Discovery alone does not establish model quality or availability for a complete interaction.

A fresh Chrome headless profile with a synthetic microphone played a generated French WAV through the browser, selected speech review, and produced a nonempty transcription without submitting it to the language model. The probe exited successfully. It left its explicitly reported temporary browser profile under the Windows temporary directory. The in-app browser control was unavailable; the test used the installed Chrome process via the local probe. No physical microphone, TTS output, agent task or user speech was tested.

One later sample reported 11,301,851,136 bytes dedicated GPU use, 212,656,128 bytes shared GPU use, 13,058,097,152 bytes available system RAM and 1,673,527,296 bytes system pagefile use. These are whole-system observations, not per-model attribution, hard reservations, peak measurements or proof of zero spill. Agent task admission is advisory and only coordinates gateways using the same ledger. A physical French conversation, audible quality, manual and automatic interruption, real agent completion and the strict hardware requirement remain open. The endpoint is `http://127.0.0.1:18096/` while its owned processes remain running.

The live controller and agent llama-server command lines were inspected: both request flash attention (`-fa on`) and Q8 key and value caches (`-ctk q8_0 -ctv q8_0`). The agent additionally requests `--no-host --cache-ram 0`; this describes configuration, not verified effective kernel selection, memory residency, or absence of paging. Their contexts are 4,096 and 8,192 respectively. The user had requested cleanup of old instances: the owned 18093 gateway and sampler were stopped after checking that no clients were connected, and its listener disappeared. Its volatile history was discarded. The 18094 and 18095 gateways still had active connections and were preserved, as was 18096.
